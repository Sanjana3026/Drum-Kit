# 🥁 Interactive Drum Kit

A sleek, responsive virtual drum kit built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. Experience high-quality drum sounds with satisfying visual feedback, playable via mouse clicks or keyboard shortcuts.

## 🚀 [Play the Live Demo](https://sanjana3026.github.io/Simon-Game/)


## ✨ Features
- **Dual Input:** Play using your mouse or keyboard keys (`W, A, S, D, J, K, L`).
- **Visual Feedback:** "Neon-glass" button animations and glow effects on every hit.
- **Glassmorphism UI:** Modern, translucent interface with a dark-mode aesthetic.
- **High-Quality Audio:** Distinct, crisp samples for every instrument (Toms, Crash, Snare, Kick).

## 🎹 Controls

| Key | Instrument |
| :--- | :--- |
| **W** | Tom 1 |
| **A** | Tom 2 |
| **S** | Tom 3 |
| **D** | Tom 4 |
| **J** | Crash |
| **K** | Kick Bass |
| **L** | Snare |

## 🛠️ Built With
- **HTML5:** Semantic structure.
- **CSS3:** Flexbox layout, Custom Animations, and Backdrop filters.
- **JavaScript:** DOM Manipulation and Event Listeners.
